## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- Git, if you want to clone the repository.
- A code editor such as Visual Studio Code.
- If the project uses Node.js tooling, install a current LTS version of Node.js and npm.

### Installation

Clone the repository:

```bash
git clone https://github.com/hagarmohamed12h-byte/Feane__Restaurant_Website.git
```

Move into the project folder:

```bash
cd Feane__Restaurant_Website
```

### Run the project

**For a plain HTML/CSS/JavaScript project:**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

**If the repository contains a `package.json`:**

Install dependencies:

```bash
npm install
```

Then use the start script defined in `package.json`. For a Vite project, this is commonly:

```bash
npm run dev
```

> Use the run instructions that match the actual files in this repository. Do not run `npm install` if the project has no `package.json`.
